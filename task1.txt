1)What is a variable in JavaScript?

a)A variable in javascript is a named box that stores data like numbers, text, or objects, making your code dynamic and reusable.


2)What are the three keywords used to create variables?

a) var: the older way of declaring variables.

   let: the modern way, used when the value can change.

   const: used when the value should stay fixed.


3)Write the syntax to create a variable using var.

a) Syntax: var variableName = value;

    ex: var age=20;
        var name="Pujitha";

    var: keyword to declare the variable

    variableName:the name you give to the variable

    value :the data stored inside the variable

    Rule: var lets you declare a variable that can be re-declared and updated.


4)Write the syntax to create a variable using let.
 
a) Syntax: let variableName = value;
    
    ex: let age = 25;            
        let name = "Pujitha";

        let :keyword to declare the variable

        variableName: the name you give to the variable

        value: the data stored inside the variable

    Rule: let, you can update the value later, but you cannot re-declare the same variable in the same scope.


5) Write the syntax to create a variable using const.

a) Syntax: const variableName = value;

    ex: const pi = 3.14; 
        const name = "Pujitha";

        const:keyword to declare the variable

        variableName: the name you give to the variable

        value : the data stored inside the variable

        
        Rule: const, you must assign a value immediately, and you cannot change or re-declare it later.

7) What is initialization?

a) Initialization in JavaScript means assigning a value to a variable at the time of its declaration(creation).
 
    ex: let city;   // declared but not initialized
        let city = "Hyderabad";  // declared and initialized with value "Hyderabad"
        const pi = 3.14;   // declared and initialized at the same time

       -> You can declare first and initialize later (with var or let).
       -> but with const you must initialize immediately.


8)What is reassignment?

a) Reassignment in JavaScript means changing the value of a variable after it has already been declared and initialized.

 ex: var age = 25;   // declaration + initialization
     age = 30;       // reassignment ->age now holds 30

     let city = "Hyderabad"; // initialization
     city = "Delhi";         // reassignment -> city now holds "Delhi"

     const pi = 3.14;
     pi = 3.14159; //  Error: cannot reassign a const

    -> Reassignment is allowed with var and let.

    -> Reassignment is not allowed with const.

    -> It simply means changing the value stored inside the variable's box.

     So, reassignment = updating the value of an existing variable.


9) What is redeclaration?

a)Redeclaration in JavaScript means declaring the same variable name again in the same scope.

        ex: var x = 10;
            var x = 20; //  Allowed -> redeclaration works with var
            console.log(x); // 20

            let y = 10;
            let y = 20; // Error -> cannot redeclare with let

            const z = 30;
            const z = 40; // Error -> cannot redeclare with const

             ->Redeclaration is allowed only with var.

            ->Redeclaration is not allowed with let and const.

            ->Redeclaration can cause confusion, which is why modern JavaScript prefers let and const.

39) What is wrong with this code?

40)What happens here?

* const -> fixed value, no reassignment or redeclaration.

* let -> allows reassignment but not redeclaration.

* var -> allows both redeclaration and reassignment.

43)Which keyword should you use if the value should not be reassigned?

a) const keyword ..
 
    Initialization required -> must be assigned a value at declaration.

    No reassignment -> once set, the value cannot be changed.

    No redeclaration -> cannot declare the same variable name again in the same scope.

  Ex:  const country = "India";   //  valid
       country = "USA";           //  Error -> Assignment to constant variable

    -> So, if the value should remain fixed (like pi, gravity, or a country name), always use const.


44)What is the difference between let and const?
    
a)    let:
        Block-scoped (only accessible inside { }).

        Cannot be redeclared in the same scope.

        Can be reassigned after declaration.

        Initialization is optional (you can declare first, assign later).

    const:
        Block-scoped (same as let).

        Cannot be redeclared in the same scope.

        Cannot be reassigned - once set, the value is fixed.

        Must be initialized at the time of declaration.


45)What is the difference between var and const?

a)    var:
            Can be redeclared in the same scope.

            Can be reassigned freely.

            Initialization is optional (you can declare first, assign later).
     const:
            Cannot be redeclared in the same scope.

            Cannot be reassigned after initialization.

            Must be initialized immediately at declaration.

  50) What is the purpose of each?

        alert()
        prompt()
        confirm()
        document.writeln()
        console.log()

    a) alert():
            ->Displays a popup message box with an OK button.
            ->Used to show simple notifications or information.

        Ex: alert("Hello! This is an alert.");

        prompt():
            ->Displays a popup box asking the user for input, with a text field and OK/Cancel buttons.
            -> Used to collect quick input from the user.

        Ex: let name = prompt("Enter your name:");
            console.log(name);

        Confirm():
            ->Displays a popup box with a message and OK/Cancel buttons.
            ->Returns true if OK is clicked, false if Cancel is clicked.

            Ex: let result = confirm("Do you want to continue?");
                console.log(result); // true or false

        document.writeln():
                ->Writes text directly into the HTML document.
                ->Often used for quick testing, but not recommended in modern practice because it can overwrite the page.

                EX: document.writeln("Hello World from document.writeln()");

        console.log():
                Prints output to the browser's developer console.
                Used for debugging and checking values during development.

                Ex: console.log("Hello World");
